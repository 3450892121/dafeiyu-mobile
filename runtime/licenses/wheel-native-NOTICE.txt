Python wheel library and source notices

The original complete wheels, Python source files, metadata and embedded
licenses are retained. The app's MIT license does not replace these licenses.
Exact wheel/member hashes and corresponding source inputs are recorded in
runtime/wheel-native-sources.lock.json. The source supplement, build recipes,
notices and replacement instructions are supplied in the same public
linux-sources.zip attachment as the Ubuntu corresponding sources.

ALSA libasound 1.2.12 — LGPL-2.1-or-later
The sherpa_onnx 2.0.1 wheel bundles the shared libasound library. Its fixed
official ARM64 wheel workflow clones alsa-project/alsa-lib v1.2.12 and runs
gitcompile, then auditwheel relocates the shared library. The exact source,
gitcompile/build files, original contributor notices and full LGPL are kept.
See alsa-lib-1.2.12-LGPL-2.1.txt and the corresponding source archive.
https://github.com/alsa-project/alsa-lib/tree/v1.2.12

GNU libiconv 1.18 in lxml 6.1.3 — library LGPL-2.1-or-later
This wheel statically includes GNU libiconv. Full libiconv source and full lxml
source (including generated C and its build/packaging scripts) are supplied so
the extension can be rebuilt and relinked with a modified library. The fixed
libxml2, libxslt and zlib source inputs and the upstream wheel recipe are also
supplied. All original copyright notices remain in these source archives.
See libiconv-1.18-LGPL-2.1.txt and wheel-native/BUILDING.txt in the source ZIP.
https://www.gnu.org/software/libiconv/
https://github.com/lxml/lxml/tree/lxml-6.1.3

Modification and replacement
You may modify, rebuild, substitute and relink the covered free-software
components under their original licenses, including reverse engineering to
debug those changes. Complete source and instructions for the statically
linked LGPL work are supplied. There is no added restriction requiring the
publisher's signing key for your own modified build. Android's normal signing
and upgrade rules still apply. See runtime/wheel-native-BUILDING.txt and the
source ZIP's wheel-native/BUILDING.txt for compatible library replacement and
wheel/APK rebuilding. No actual rebuild of these upstream libraries on a phone
is claimed by providing these materials.
