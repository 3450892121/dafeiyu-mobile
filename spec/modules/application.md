# 原生应用

目标：提供用户个人使用的清爽安卓应用，点一个图标进入，单 App 完成运行是优先目标。

范围：设备条件检查、QQ 运行状态、功能复刻清单及使用入口。颜色、字号和间距统一放在主题资源里；用户可读内容全部为中文。

输入：本机系统信息、功能清单、未来 QQ 运行内核的真实检查结果。

输出：区分未安装、未验证、未登录、验证挑战、已连接和暂停的状态；初始化阶段必须明确“尚未接入 QQ”。

非目标：不提供模拟已登录、虚构二维码或无效的启动成功提示；不让用户在界面里替工程选编程语言或运行库。

依赖：QQ 接入模块提供检查结果，本地数据模块存储本项目设置；功能展示来自 `../features.json`。

验收：先通过工程检查、APK 构建及安装启动；后续必须在真机核对权限、界面、重启及后台恢复。具体判据见 `../acceptance.md`。
