# 本地数据

目标：让新手机版拥有自己的设置、聊天、记忆、任务与备份，和原机器人完全隔离。

范围：应用私有目录、独立数据库、密钥保护、按会话控制的资料可见性以及备份恢复。

输入：本实例的事件和用户在本应用输入的配置；初始化不读取原项目的真实配置或数据库。

输出：本机持久数据、仅含必要非秘密字段的诊断，以及经用户操作产生的备份。

非目标：不复制旧聊天、旧记忆、旧登录资料或原号群名单，不把新产生的私密数据提交到 Git，不自动建立与服务器的同步关系。

依赖：原生应用提供私有存储位置，其他模块通过此模块访问数据。聊天、记忆等敏感字段及接口密钥使用本实例 Fernet 材料加密，数据库文件保存在安卓私有目录；这不是整库 SQLCipher 加密。安卓停止服务时以 Android Keystore 包装材料，启动时仅向本 App 私有运行目录解封。系统保护行为须真机验收，不在工程中写真实值。

同一安装来源的新版 APK 须支持在原应用上保留数据覆盖更新。更新沿用原应用 ID、签名身份及独立实例目录，保留设置、加密材料、聊天与记忆、任务以及 QQ 的既有登录目录。已有资料无法读取时应停止并提示原因，不能以新空库、空配置或新密钥替换它们。QQ 是否仍在线与用户资料是否保留分别核对。更新失败时不以卸载或清数据作为恢复方式。

备份使用口令派生密钥与 AES-GCM，SQLite 使用一致快照。恢复先校验归档路径、大小和数据库，再按目录替换并在提交失败时回滚；保留当前本机控制令牌并保持机器人暂停。备份范围与源码见 `runtime/mobile_backup.py`，不带 QQ 客户端、登录缓存或 CPU 模型。
