# 媒体与工具

目标：在手机本地调度原项目大肥鱼的媒体及工具能力；允许联网使用用户配置的 AI 和相关网站。

范围以 `../features.json` 为准，包含图片、表情、文件、搜索、视频、B 站、空间、提醒等。语音相关能力和翻唱属于手机确实不可行时可省略的项目，独立语音消息的收发分别记录；普通点歌与音频文件分享不能因此自动删除。

输入：会话授权、资料链接、附件和本机或网络服务返回值。

输出：实际文件、图片、公开动作及其回执；失败、超时或结果未知须如实呈现，不能假装已经制作或送达。

AI 线路的密钥只用于该线路明确配置的服务。绘图和向量检索不得取任意聊天线路或来源不明的全局密钥发送给固定接口；同一主机的不同套餐路径也不得混用。没有匹配配置时明确提示缺少相应接口，记忆与表情检索保留不依赖向量接口的回退。带鉴权请求重定向时不得把密钥转交到新的请求。

视频理解还依赖字幕、取帧、音轨转写等。省略语音发声不等于省略听懂视频；需要逐条核对 ARM64 工具与手机耗时。

非目标：不依赖原电脑的 TTS/CUDA/翻唱服务，不擅自登录 B 站或空间、不向真实平台发布测试评论。

依赖：大脑发起获准任务，QQ 接入负责交付，本地数据隔离任务和登录资料。第三方组件在引入前核对许可与来源。
