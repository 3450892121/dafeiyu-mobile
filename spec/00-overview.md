# 项目总览

## 已确认的目标

开发一只独立的“手机版大肥鱼”，复刻参考项目中大肥鱼的功能。参考项目的机器人继续留在原处运行；本项目使用新 QQ 小号，聊天和记忆从头开始。

用户已选择：安卓（未 Root 或不清楚）、允许联网调用 AI、个人使用、点图标打开、清爽简洁界面、交付安装包、使用 Git 并沿用已有身份。用户补充：只做普通 QQ 小号，尽量合成一个软件；语音相关能力和翻唱若手机确实无法实现，可以不做，其余功能仍是完整复刻目标。

“独立运行”的验收含义：QQ 接入、大脑、记忆、任务和界面在手机上运行；电脑和用户现有服务器关机后仍能使用。外部 AI、搜索、图片生成和公开网站允许联网访问，不绕回原项目的服务。

## 执行边界

- 写入范围仅为本项目根目录。
- 唯一获准参考的外部项目为相邻的 `大肥鱼服务器版/`，仅只读其说明和必要源码。
- 不搬走原机器人，不修改原项目、不动原号、不继承真实运行数据、不操作服务器。
- 不访问其他项目；运行依赖可在本项目私有工具目录内下载，不能改系统配置或其他项目环境。
- 先交可运行骨架，逐项复刻；界面、接口和模拟通过不能冒充完整功能交付。

## 功能与模块

完整功能清单仅维护在 `features.json`；每项包含参考源码、是否允许省略与验收证据。

| 模块 | 规格 | 职责 |
|---|---|---|
| 原生应用 | `modules/application.md` | 一个图标、清爽界面、设备检查和真实运行状态 |
| QQ 接入 | `modules/qq-access.md` | 普通 QQ 小号、接口适配、独立登录与断线处理 |
| 大脑 | `modules/brain.md` | 对话理解、人设、成长、记忆、做梦、自主行为及权限 |
| 媒体与工具 | `modules/media-tools.md` | 图片、文件、搜索、视频、B 站、空间、提醒及可选语音 |
| 本地数据 | `modules/local-data.md` | 全新本地资料、隐私隔离、备份和恢复 |

## 工程安排

原生安卓界面采用 Java 与系统 UI 组件，统一主题；使用一个 APK 内的私有 Linux 用户态运行层承载 Python 大脑及普通 QQ 小号接入，不另装 Termux，不依赖原服务器。运行所需的公开组件按官方来源校验后在应用内初始化。

参考项目的 MIT 功能源码可以复制复用到本项目 `runtime/core/`，作为独立实例适配；这不搬动、替换或停用原机器人。只复制源码与必要的静态界面，不复制真实配置、数据库、聊天、账号、人设经历或登录状态。版本信息见根 `version.properties`。

先实现可替换的 NapCat Shell 接入，以完整覆盖参考项目已用的 QQ 接口。上游组件保持独立并保留其许可，通过应用内安装官方完整组件使用，不复制 SnowLuma 专有组件。不能把接口或登录实现的变化说成风控已经改善。候选事实与来源见 `qq-access.md`。

用户已要求先完成全部代码和电脑侧隔离检查，最后才提供手机做真机验收；未取得真机不阻塞可独立完成的实现，但真机结果仍不得提前打勾。

## 非目标与未确定项

- 不做官方 QQ 机器人通道，不充当原服务器的遥控面板。
- 不承诺全天候不掉线、无风控或不封号。
- 不把源码可见许可、Linux arm64 产物等同于可随意内嵌或原生支持安卓。
- 手机型号、安卓版本、可用内存、内核限制、QQ 接入和熄屏运行均须现场验证。
- 单 App 内置 QQ 运行层能否满足兼容和许可条件尚未验证；不得静默改成要求安装第二个 App。
- 不自动省略看视频所需的字幕或声音转文字；它与语音发声、翻唱的范围分别判断。
